# N3 CFAR contract (150 MHz, 2048 fftshifted power bins)

Input power is uint32, already fftshifted by spec_front. CA/GO/SO map to0/1/2. The only boundary policy is circular wrap, matching sim/golden/cfar.py; the six mandatory tests are three modes with interior targets and with targets crossing the two spectrum edges. The old phrase "two boundary treatments" does not define another numeric policy and does not authorize inventing zero padding. Clustering remains linear left-to-right and does not join first/last targets.

N=2^N_SHIFT (0..6), guards0..31; left/right sums40 bits. CA divides the combined sum by2N; GO/SO divide max/min byN, flooring before alpha. Alpha unsigned Q8.8, threshold=min((noise*alpha)>>8,0xffffffff). Strict CUT>threshold. DC_MASK=0xff disables masking; otherwise suppress center±width. Invalid configuration refuses input and reports STATUS.INVALID; framing errors are sticky until reset. All configuration snapshots at first input handshake, TLAST must occur on bin2047.

The frame is captured in five replicated synchronous BRAMs to supply CUT and four incremental-window taps. Initial sums require N clock reads, then one bin issues per enabled clock. This is a framed engine, not zero-latency continuous input: capture and processing do not overlap. At default N=16, no stalls, the estimated service bound is above30.72MSPS at150MHz; actual full-chain throughput must be measured in N4. Output stalls freeze pipeline/addresses/sums. No overflow is silently discarded.

The exact32x16 threshold multiplication uses one16x16 low DSP48 product and two8x16 high fabric products, followed by registered32-bit high recombination and48-bit total. A single DSP48 cannot directly accept32-bit multiplicands; truncating to25 bits would violate the golden model. dB uses the same leading-one/mantissa ROM as N2, with pipelining and a0x8000 zero sentinel. m_axis_thr is signed Q8.8 raw power dB, not calibrated dBFS. The logarithm constant multiplier may consume another DSP; the one-DSP limit refers to the threshold product. From RAM read issue to detector output-valid takes eight enabled clock intervals; the registered independent-output broadcaster adds one interval. Backpressure freezes these intervals; initial frame capture and2N initialization clocks are additional latency.

Targets are inclusive start/stop, first maximum on ties (including bridged gap power); merge up to GAP missing-hit bins, include intervening powers in sum, exclude trailing gap. Sum saturates uint32. Keep first32 targets, mark flags bit0 in every retained record on overflow. Record little-endian layout: uint16 start,stop,peak_bin,flags; uint32 peak_pwr,sum_pwr. Two list banks publish atomically with sequence count; PS reads sequence before/after the window and retries on change. irq_list_ready pulses once per published frame. AXIS emits128-bit records, TLAST on last target; empty frames emit no records and are reported by count/IRQ.

Occupancy uses2048 saturating uint16 hit counters, read individually through AXI-Lite. A clear token changes only between frames, clearing counters and occupancy frame count. Frame hit count and optional count-limit alarm are available. PS reads a stable snapshot by disabling new frames and waiting idle; live counter reads are individual snapshots, not an atomic array snapshot.

No board constraints, pin assignments or third-party source changes are needed for this step. Full implementation and simulation results are recorded only after acceptance.
