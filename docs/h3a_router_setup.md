# 便携路由器接线与设置

本说明用于之后切换网络；当前开发板仍通过现有网线工作，不需要现在改动。

1. 电脑先连接路由器，在其管理页面把LAN地址设为192.168.2.1、掩码255.255.255.0。保存后按路由器提示重新连接。
2. DHCP地址池使用192.168.2.100–192.168.2.200，避免分配开发板固定地址192.168.2.99。若实际路由器已经使用该地址，先修改路由器，不能和开发板冲突。
3. 开发板GE_PS网口接路由器LAN口。电脑和手机连接该路由器的普通Wi-Fi，不使用隔离访客网络。电脑网卡改为自动获取地址；若保留手动配置，地址需独立且与路由器、开发板均不重复。
4. 若路由器支持双频，电脑和手机优先使用5GHz。只有2.4GHz时可固定信道1；信道13仅在当地与设备允许时选择。不改变国家/地区设置来解锁信道。
5. 在电脑验证：`ping 192.168.2.99`，随后`ssh xilinx@192.168.2.99`。原SSH主机指纹和密钥不因换路由器而改变；若提示指纹变化，应核对实际设备。
6. 上位机连接地址保持192.168.2.99。板端hostlink服务启动后，手机浏览器打开`http://192.168.2.99:8080`。该页面依赖服务运行，板子仅上电不等于网页已启动。

路由器设置与真实无线联通尚未验收；上位机顶栏“手机监看二维码”按钮已实现（电脑图标），需源码版本与requirements中的qrcode依赖；旧exe尚未包含。换网络时先结束测试，避免中断文件取回和采集。配置B发射须另行按实际天线与安全确认流程执行，本文不授权发射。
