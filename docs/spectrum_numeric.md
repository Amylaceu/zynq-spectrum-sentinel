# 频谱定点契约（P2.2）

本模型调用本机 Vivado 2025.2 的 XFFT v9.1 位准确 C 模型。DLL 只缓存于忽略目录 build/work/，不随仓库分发。运行前加载 tools/env.ps1；不使用 NumPy FFT 冒充硬件位准确结果。

| 环节 | 规定 |
|---|---|
| ADC 输入 | int16 I/Q，12 位左对齐；函数也接受非 ADC 对齐的仿真整数 |
| BH4 窗 | periodic，18 位 Q1.17，最近整数，饱和至 [-131072,131071] |
| 加窗乘积 | 有符号 34 位乘积，算术右移 17，不额外四舍五入；16 位送 FFT |
| FFT | 2048 点，pipelined，输入/原生输出 16 位，18 位旋转因子，收敛舍入，固定缩放，无 BFP，自然序 |
| 缩放顺序 | [2,2,2,2,2,1]，阶段 0 在前，总计右移 11 位（1/2048） |
| 24 位输出表示 | 原生 16 位输出左移 8 位，Q1.23；低 8 位为零，绝不声称增加了有效精度 |
| 功率 | I²+Q²，48 位无符号结果，右移 16 得 uint32 Q2.30 |
| Welch | 转 signed 64 位做差，P + ((pw-P) >>> shift)，保持下降时算术右移 |
| dB | 原始整数功率 10log10(p)，Q8.8；p=0 输出 -32768 作为下限标记；转 dBFS 时减去 10log10(2^30) |
| 对数近似 | 前导 1 的指数 + 8 位尾数查表；内部 Q16.16，最后一次舍入到 Q8.8 |

runbook 的 P3.2 指定 FFT 输入 16 位，P2.0 指定输出传输宽度 24 位。scaled FFT 的原生输出仍为 16 位，本契约用左对齐统一两者，P3 必须按此打包，不能直接把 24 位配置视为多出 8 位精度。

BH4 的 -90 dBc 验收针对量化窗的频响；16 位 scaled FFT 的量化噪声会限制实际深旁瓣测量。分别验证窗函数频响与位准确 FFT 的峰值/缩放/定点数值，不把窗的理论抑制宣称为硬件整条链路动态范围。

fft_fixed 返回自然序 N×2 int32；在进入 CFAR、显示等使用频率顺序的模块前，显式沿频点轴 fftshift。窗口和 FFT 不自动改动频点编号。
