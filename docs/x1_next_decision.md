# X1 未达标后的诊断交接

当前结论以 `runbook/STATUS.md` 和 `board/measurements/x1_acceptance_summary.json` 为准。
本文件为后续处理建议，不能据此突破三轮限制或启动新的射频试验。

最新电脑端复核见`docs/x1_frozen_replay_summary.md`：五个历史窗口证实用户所见95.45MHz高检出，但信号身份尚未确认。96帧同输入模型对照支持优先核验保护窗，GUARD=8时95.8MHz检出94/96；尚未部署、不替代联合验收。文档已列明只追加一轮的具体方案，或保留FAIL暂缓X1转X2，等待用户明确流程选择。

## 已知事实

- 同位流的逐位仿真、最终整机时序、有限自检均通过；RF质量验收单独判断。
- r1/r2容量告警为0，但95.8MHz周期快照检出率分别为66.02%/59.22%，未达80%。
- r3降低门限后，98MHz容量告警升至35.24%。单独调整平均和门限尚不能满足联合指标。
- 每窗只保存启动时一帧功率，未保存每个漏检快照对应的同帧功率和门限，无法证实漏检根因。
- 电台窗口LO=96.4MHz、目标95.8MHz是预定配置，两者相差600kHz，不是频率计算错误。

## 如获授权继续，建议先做的工作

2026-11-03补充：下述第1项已推进至96组同帧RF功率与黄金模型诊断，详见`docs/x1_paired_diagnostic_summary.md`。门限/hit/mask为模型重建；诊断不能替代连续RF联合验收，也未解除三轮限制。本节其余内容保留为后续建议。

1. 设计同帧诊断捕获：功率、阈值、hit、屏蔽状态、聚类前后段及帧序号一致，分别保留检出与漏检样本。先仿真和离线验证采集一致性，再安排新的受控板测。
2. 离线区分宽度筛选、段内峰偏移、参考窗信号污染和非平稳干扰的影响；这些目前仅为待验证原因。不得直接给95.8MHz硬编码放行或屏蔽其他频率来通过指标。
3. 用同一批冻结原始帧对照参考/保护窗、合并间隙和门限，另外留出独立时段验证。扩大合并间隙可能合并相邻信号，必须记录该取舍。
4. 如用户决定暂缓X1质量目标、先做X2，须在STATUS明确记录这一流程例外及X1未达标事实，不能自行标为DONE。

当前不需要更换天线、衰减器、SD卡或复位板卡。故障证据不足以认定硬件损坏。后续测试仍须配置A确认、TX关闭和射频安全检查。
