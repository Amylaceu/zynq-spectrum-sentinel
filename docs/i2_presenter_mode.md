# 讲解模式的实现与操作

历史实现检查点：此入口已被 `runbook/J_polish.md` 文末 J 修订 v2 取消。
后续产品采用九个功能页与页内开始按键，不继续扩展讲解窗口、提词或计时。
下文仅用于复现本轮原始测试，不代表最终操作手册。

当前仅接收。固定使用 `sentinel_v2_100m`（100 MHz、3.84 MSPS），本阶段没有修改位流、模型、CFAR或冻结孪生绘制代码。

## 入口与文件

- `tools/host/sentinel_host/presentation.py`：讲解控制、回复关联、提词与计时、回放门禁。
- `tools/host/scenes.yaml`：七个场景的顺序、说明、建议时长和可用状态，可修改提词。
- `tools/host/sentinel_host/shell.py`：现有主窗口切换为投影窗口，保留同一个孪生画布。
- `tools/host/sentinel_host/gui.py`：网络请求在入队时分配序号，断线后清空旧请求，避免重连时执行过期操作。
- `tools/i2_board_check.py`：候选包部署及有界真板集成测试；标准输入或无回显终端读取提权凭据，不保存。
- `board/measurements/i2_software.json`：软件检查及源码摘要，附 SHA256。
- `board/measurements/i2_board_r*/`：每轮真板原始结果、投影及提词截图、独立停止检查，不覆盖失败轮。

源代码启动（在仓库根目录执行）：

```powershell
$env:PYTHONPATH = ".;src/ps;tools/host"
.\.venv\Scripts\python.exe -m sentinel_host --connect 192.168.2.99 --present
```

需要先启动具有 `resident` 元数据的常驻服务。普通 monitor 和旧版仅报告 monitor 的服务不启用场景按钮。主窗口投影，独立窗口显示提词和计时；单显示器时提词浮窗会遮住部分投影，可拖动或关闭浮窗，底部场景条保留。

## 操作

- `P`：进入/退出讲解模式；正常退出请求静音待机，不能把退出窗口视为硬件停止确认。
- `1`–`7`：对应场景；未实现的按钮保持禁用。
- `PageDown`/右箭头、`PageUp`/左箭头：在当前可用场景间切换；普通翻页笔使用同一按键路径。
- `Esc`/红色停止：请求板端受控停止；回复只表示命令处理，硬件归零仍须独立检查。
- `F11`：投影主窗口全屏。
- 默认电台只提供已验证的 95.8 MHz；没有把不支持的频率参数发送到服务。

## 真实性与故障处理

仅预检、监测识别、收听、性能四项接入实时控制。全景快扫等待 I5，WiFi 等待 I4 门槛，空口使用回放路线但素材注册等待 I6，因此当前三项灰显。性能场景复用已存在的系统面板，不宣称完成所有量化性能汇总。实验模型原准确率未达标结论保留。

按钮按下后显示启动中；只接受与当前命令序号、场景 ID 匹配的就绪回复。超过两倍目标时间显示超时并锁定新请求，避免排队的旧场景突然运行；可等迟到回复，或请求停止。重连清除预检许可并重新执行预检。往返时间包含排队、板端处理和返回，不称为纯网络 RTT，也不以板内耗时替代点击至就绪时间。

回放注册须指向发布/项目目录中的 `.zsr`，检查完整清单、文件摘要和全部记录，要求真实且非空。实时转回放先请求 idle，收到就绪才断开并播放；停止可取消尚未开始的回放。投影标题和模式角标持续显示 REPLAY，不冒充当前接收。当前没有注册兜底素材，所以按钮禁用；测试会话仅用于软件检查。

计时按单调时钟的差计算，不靠定时器回调次数累加；建议总时长 4 分钟，超时变色，不据此宣称完整讲解已完成。缺项及回放验收保留到后续阶段。

## 音量

当前候选继承 I1 已试听确认的 ROUT2=0 dB；OUT1/P1保持 −6 dB 上限。没有开放正增益。用户确认仅为“音量合适”，不能扩展为新候选所有场景均经过人工听音验收。

## 已保存的短测结果
