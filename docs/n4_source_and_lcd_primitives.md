# N4源选择与LCD基础组件验收

本记录是N4子步骤，不代表sentinel_v1、上屏效果或M-A已完成。

## 源选择

src/rtl/src_mux/src_mux.v提供RF、回放、三音DDS测试源和RF+定点注噪四种模式。输出低16位I、高16位Q，2048字TLAST，TUSER为模式。DDS采用I=cos/Q=sin，正FCW对应正频率；1024×16正弦表、32位相位、三路独立FCW与幅度，先逐路算术右移15位再求和饱和。

噪声使用P2固定的Galois多项式0x80200003，每路12次取样、每次前进12步，12位均匀字求和减24570。I/Q独立seed；仅被接受的mode3输入推进随机状态。注入使用unsigned Q1.15幅度、signed乘法和算术右移15，再与RF相加并饱和16位。没有用替代高斯分布或浮点噪声冒充逐位匹配。

RATE_DIV为Q16.16时钟周期，默认320000即150MHz下4.8828125周期/样本（30.72MSPS名义节拍）。计数在全局流水可推进时工作，背压期间暂停；故它不保证下游停顿时仍有恒定墙钟速率。帧首参数锁存，EN关只阻止新帧，已有帧排空；ARM_TOKEN在帧间且流水排空后复位相位、seed、节拍和统计，FRAME_LIMIT=0连续或按指定帧数停止。软件改参数应先停上游、禁用并排空，再配置/ARM/使能。

N4_src_round2：8组、16384个IQ字逐位一致。包含四模式、三频DDS、幅度0/32768/65535注噪和饱和、随机输出背压、重新ARM及帧数限制。时序首轮WNS=-0.400ns，关键路径为帧首RATE选择到节拍比较再到DDS地址；将节拍值先寄存并保持相位寄存器边界，第二轮WNS+0.198ns，内部hold+0.157ns。资源3182LUT、1564FF、0BRAM、8DSP；实际综合将正弦查表实现为逻辑，按实测记录，不按属性声称BRAM。完整系统setup/hold及持续速率仍待验收。

## LCD总线与区域组件

- lcd8080_bus.v复用原板上验证过的72条初始化指令（68次总线写、4次延时），RESET/STARTUP参数保持原值。export_lcd_init.py从原模块提取，不修改原工程。
- 每字起始锁存BUS_PHASE，运行中改变不会截短正在进行的写脉冲；0钳到1。16位命令/数据接口可接后续渲染器/命令调度。仿真检查68次初始化写、RS/数据、2/4/1周期脉宽、字中途切换和空闲管脚。
- lcd8080_region.v生成0x2A/0x2B/0x2C窗口、指定数量像素、区域填色、0x33滚动区域和0x37滚动起点。坐标、总滚动行数及起点越界均拒绝，不发总线数据。滚动行数之和使用18位，避免16位参数求和绕回后伪装480行。
- 区域测试使用真实800×480边界，检查83个命令/像素字、超过255的坐标、随机和长背压、填色、TLAST、无效矩形/滚动/求和溢出拒绝。第1轮基础例和第2轮扩展例均通过。

这些是数字仿真，不能替代用户对屏幕的逐档目视验收。当前还缺少谱线/门限同帧缓存、渲染和瀑布调度、UI脏区域、perf_mon、BD完整连接及上板程序。实际布局按用户确认的docs/n4_display_architecture.md，右上列表分页、瀑布右侧留空。
