# 解调与实际屏幕参考约定（P2.6）

用户已确认屏幕是 ATK-MD0700 V2.4、SSD1963、J22 8080 并口，800×480。参考图据此为 480 行×800 列 RGB565，不使用手册默认的 600×1024 或 J26 RGB 时序。当前只生成像素，尚未实现/下载 SSD1963 接口；P3/P4 必须另行适配实际已验证接线，不可直接复用 rgb2lcd。

布局：频谱 x=0..719、y=0..159；瀑布 y=160..359；其余为 UI。DPX 为 128×360 个8位计数，最近邻映射到频谱区域。256项整数调色板从黑、蓝、青、黄到红，后续 RTL 应导出使用同一 LUT。

频谱、峰值、门限均接收 Q8.8 dBFS，默认范围 [-100,0] dBFS。超过720频点时按整数边界分组取峰值；列与上一列之间的全部纵向像素画曲线。颜色和虚线规则保持手册：平均谱07FF、峰值FFE0、门限F800（每4列画2列）、目标框07E0。合成次序为 DPX、平均谱、峰值、门限、目标框、UI，UI色键F81F透明。瀑布 ring 从 wf_head 行开始显示。

FM 参考将输入相位量化为16位（π对应32768），相邻相位差模2π，输出弧度/样本；第一点为零。AM 幅度为 unsigned16、Q1.15，直流估计 dc += (amp-dc) >>>10，初始0，输出保留启动瞬态。

重采样参考使用有理比例 Kaiser 多相滤波，输出48kHz，离线函数补偿群延迟。它是音频幅频/采样率参考，不能声称与尚未实现的 RTL CIC/FIR 逐位一致；后续 P3 按 SQNR 门槛验收，并显式对齐群延迟。
