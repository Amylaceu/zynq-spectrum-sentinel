# X1 冻结数据复核与下一轮建议（2026-11-03）

本次仅在电脑端复核历史文件，不连接开发板、不更改部署参数。X1 仍为 FAIL，X2 尚未开始；原三轮验收和全部天线记录保留。

## 用户补充的 95.45 MHz 观察

用户反馈“两根天线在测试过程中95.45检出率特别高”。复核五个已完成的120秒窗口，使用实际LO读回、2048点FFT和原±25kHz容差；每条遥测最多计一次，缺失快照仍计入分母：

| 历史窗口 | 95.45 MHz 附近 | 原目标 95.8 MHz 附近 |
|---|---:|---:|
| 第一根：粗长、短馈线 | 104/104（100%） | 16/104（15.38%） |
| 第二根：细短、长馈线，首测 | 105/105（100%） | 61/105（58.10%） |
| 第三根：型号未知 | 104/104（100%） | 50/104（48.08%） |
| 第二根：同期重测 | 101/102（99.02%） | 21/102（20.59%） |
| 新找到的同频段天线 | 107/107（100%） | 26/107（24.30%） |

这些窗口中95.45MHz附近的峰值均落在bin 518，即实际LO=96399998Hz时的95451248Hz（约95.45125MHz），聚类宽度中位数为4bin。该频点的检出率已接近饱和，区分天线的能力有限；此前基于95.8MHz的排序只描述对应时段和频点，不能代表天线整体优劣。

**暂称“95.45MHz附近谱峰”，不直接称为已确认电台。** 当前没有独立信号真值、该频点的IQ/导频/听音或改变LO后的追踪记录，不能排除外部干扰、内部杂散等来源。频谱峰稳定本身不能证明信号身份。LO=96.4MHz时它偏移约−950kHz，虽在3.84MSPS数字范围内，但在当前1.5MHz标称RF带宽的±750kHz以外；滤波器有滚降，不能据此扩大标称有效通带。

未来若验证来源，应在只接收状态改变LO并检查绝对频率是否保持，不按固定基带bin认定为真实射频信号。该诊断不作为替换95.8MHz验收目标的理由。

## 同输入、单因素的模型对照

使用已配对的`x1_diagnostic_rf_r2.json/.npz`共96组门控功率帧，先重新核对全部原硬件计数和目标，再作10种预先列明的单因素对照。未训练或自动选择部署参数。门限、hit和替代目标均为PC模型输出。

| 单因素对照 | 95.8MHz模型检出 | 本组模型容量告警帧 |
|---|---:|---:|
| 原配置：CA，N=16，GUARD=2，ALPHA=1974，宽度2，间隙6 | 77/96（80.21%） | 0 |
| 最小宽度改1，仅作诊断 | 90/96（93.75%） | 0 |
| 合并间隙改2 | 77/96（80.21%） | 0 |
| 合并间隙改12 | 77/96（80.21%） | 0 |
| GUARD改8 | 94/96（97.92%） | 0 |
| GUARD改16 | 95/96（98.96%） | 0 |
| N改32 | 92/96（95.83%） | 0 |
| N改64 | 96/96（100%） | 0 |
| ALPHA改1536 | 88/96（91.67%） | 0 |
| 模式改SO，同一ALPHA | 96/96（100%） | 0 |

这表明在这组冻结输入上，参考窗/保护窗值得优先核验；它不证明射频物理根因，不证明实测虚警概率不变，也不保证独立时段达标。SO同ALPHA并非等虚警概率比较。关闭宽度筛选可能增加孤立杂峰，不建议直接据此部署。扩大间隙没有改善本组数据。

96帧的前/后半段各48帧也单独保存：原配置31/48与46/48，GUARD=8时46/48与48/48。它们是相关的描述性分段，不是独立留出验证。这组门控数据中95.45MHz仅39/96，且后半段0/48，因此连续窗口的高检出结论不能外推到所有工作方式/时段。

**表中的0告警只适用于这96帧、LO=96.4MHz的有限输入，不是98MHz连续容量窗口。** 不能据此把X1改成DONE。

## 已准备的有限板测建议

需要用户明确决定是否突破原三轮上限。建议只追加一轮，使用原`sentinel_v1b`位流，只改可配置的GUARD=8，保持CA、N=16、AVG_SHIFT=3、ALPHA=1974、MIN_WIDTH=2、MERGE_GAP=6、DC_MASK=3、无额外mask。选择8而非在本数据上刷到最高分，是为了先检验较小的保护窗调整；这仍是探索性建议，需要独立实测。

1. 电脑端准备独立入口，显式记录GUARD/N；保留冻结`monitor_x1.py`、旧驱动和前三轮软件/日志/哈希。原入口没有GUARD选项，不能直接向它传不存在的命令参数。
2. 对新增入口先测试参数校验、停流后配置、实际寄存器读回、频率换算、漏快照计分和安全退出。核对现有RTL配置范围和相应逐位仿真；必要时补一组GUARD=8定向仿真。不得放松时序或频率容差。
3. 当前新天线接RX1A、TX空，配置A仅接收，3.84MSPS、RF带宽1.5MHz、BUS_PHASE=3。先查独占锁及GPIO/SRC停止状态，再启动。
4. 同组参数下分别运行98MHz和96.4MHz各120秒。原指标不变：98MHz容量告警上界<5%，95.8MHz±25kHz检出≥80%；缺失快照保守计分，采样溢出必须为0。95.45MHz仅附加统计。
5. 两窗口均保存独立新标签的原始JSON、执行回执、日志、SHA256、软件/位流清单、温度、TX衰减、boot_id及停止状态。结束确认GPIO/SRC=0。需要屏幕目视时等待用户回报。
6. 一轮仍失败则保留FAIL并停止追加调参。若用户同时授权暂缓X1、转做X2，在STATUS单独记流程例外；否则不得自行跳过。

若用户优先推进带宽，也可明确选择暂缓X1，保留FAIL后进入X2。X2不会因此被视为解决了X1质量问题，M-A完整验收仍需如实注明缺项。
