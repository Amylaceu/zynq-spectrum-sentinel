# P2.9 调制识别训练与验收

当前状态：1300段小数据端到端检查已通过，另有3项网络/数据测试和分层隔离审计通过；26万段正式数据已生成，SHA256、分层比例和集合无交叉审计通过；40轮融合模型训练在后台运行。全量数据、40轮训练、88%准确率、INT8导出和量化损失均不能提前标为完成。

数据集要求不变：10类×13个SNR（-4..20dB，步长2）×2000段，共260000段，每段1024点；按每个类别/SNR单元8:1:1分层划分。样本使用独立且唯一的生成种子，manifest记录文件和源码哈希。原始输入保存ADC12左对齐的int16；不会把同一波形的相邻切片分到训练和测试集。

采样率480kHz指PFB输出3.84MHz经过DEC=8后的捕获速率，并非把宽带RF采样率改成480kHz。AM/FM的300..3000Hz消息在1024点中需要足够时间跨度；不能拿30.72MHz的1024点（约33微秒）冒充充分观察音频调制。后续捕获/板端推理必须匹配训练的有效采样率及带宽。数字调制的4..16点/符号随机化保持不变。

带内SNR按信号带宽定义。两径瑞利、频偏、相位和IQ失衡均随机化。对含噪信号做总功率AGC，再进行ADC量化，避免低SNR时单纯因噪声幅度上升造成大面积削顶；裁剪片段计数记录在manifest。

HOC先在int16尺度下去均值、取整，以实际峰值选择48位安全右移，调用同一 moments_fixed/特征函数，不用浮点理想HOC代替。IQ分支做去均值和单位复功率归一化。HOC做log1p后使用仅从训练集拟合的均值/标准差。

融合网络按runbook规定的3层CNN、16维HOC分支、64→32→10分类头。对照模型关闭HOC分支。CPU线程数受控；最佳checkpoint按验证集总体准确率选择，独立测试集仅在训练结束后评估。未达到SNR=10dB总体88%会明确报失败，不伪造数值或放宽阈值。

小数据测试：`tools/run_amc_training.ps1 -Smoke`（每单元10段、1轮，仅检查数据/训练/保存/测试流程，不作准确率验收）。
