# HOC 数值范围与模型假设

P2.5 输出 M20、M21、M40、M41、M42、M60、M61、M62、M63，每项均为 `(实部48位累加和, 虚部48位累加和)`，另有 count、norm_shift 和 overflow 元数据。实数矩的虚部为零。

输入 int16 先算术右移 norm_shift，再进行精确整数乘方。累加器按有符号 48 位回绕；任何前缀溢出都会置 overflow，特征函数拒绝使用溢出数据。CPU 最后根据 count 和 Q 格式归一化；HLS 后续必须使用同一回绕及输出规则。

1024 点、I/Q 可能同时满幅的保守归一化为右移 10 位。若软件已测得更小的输入峰值，可以按 recommended_norm_shift(count, peak) 降低右移量以保留精度；不可仅凭正常波形幅度假定不会出现满幅。

浮点理想星座的 |C40|/C21² 理论值为 BPSK=2、QPSK=1、16QAM=0.68。测试同时验证 1024 点实际捕获长度的定点特征误差小于 0.05。不能将较长片段增加的归一化右移当作无损处理；初轮 65536 点 16QAM 的定点误差约0.0705，随后按真实 1024 点捕获长度复核，未放宽误差阈值。

九个偶数阶矩采用零均值、奇数阶矩为零的累积量公式。调用者应先去除 DC。对于不对称分布或残留 DC，这组公式是特征近似，不能声称等于一般分布下的全部六阶联合累积量。单独以联合累积量的集合划分定义验证了四个六阶公式的系数和符号。

后续训练与板端软件应调用同一定点矩/特征路径；理论星座测试不等于成形信号的识别率，AMC 的准确率仍以独立测试集实测为准。
