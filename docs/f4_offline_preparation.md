# F4 电脑端准备与后续接入

## 当前结论

本轮只完成独立数值处理和证据存储模块，不访问开发板、读卡器或正在读取的镜像。不改现有发布入口、monitor、RF驱动、RTL、位流、模型及CFAR参数。F4板测尚未开始，不能据此填写整机稳定性或宽频接收指标。

用户报告SD备份约29%处出现Win32 Disk Imager错误1117（I/O设备错误）。这是一次失败的读取，当前不完整镜像不能用于恢复。建议保留以前成功的备份，新读取使用新文件名；更换USB接口或读卡器后再读，不进行Write、格式化或源卡修复操作。若反复在相同进度失败，先排查读卡器和源卡，不反复重试。尚未完成的镜像不做SHA256验收。

## 数值处理约定与离线结果

1. 配置A覆盖70–512 MHz，55个LO；配置D覆盖512 MHz–2.7 GHz，274个LO。各段有效宽度20 MHz，相邻中心一般相差8 MHz。重叠用于覆盖LO附近的DC屏蔽区和RF边沿；不能简单以20 MHz步进留下测量缺口。
2. PSD输入为复数ADC计数，满量程参考2048。Hann窗、50%重叠，双边谱不乘实信号单边谱的2倍系数。输出为相对`FS²/Hz`或`dBFS/Hz`，不是dBm、绝对场强或射频SNR。
3. 拼接在**线性功率**域求平均；屏蔽LO附近±150 kHz及有效通带边沿。覆盖次数为0的输出保持NaN，不能替换为噪底，也不能跨屏蔽区插值填洞。
4. 两种天线各自输出，AGC和天线频响未校准，不能将两组纵轴解释为连续的绝对功率测量。频段名称仅作参考，不能由峰位置断言具体业务或调制。
5. 合成A/D频谱分别有44,200和218,800个10 kHz输出格点，全部有覆盖，已知合成谱峰定位误差最大5 kHz。该结果验证频率轴和拼接代码，不验证实际AD9361通带。
6. 单音积分功率与随机复数IQ的Parseval检查通过；半满量程复正弦的归一化积分功率为0.25。缺口、负频率方向、线性平均均有独立测试。

## 长测证据约定

`EvidenceStream`在文件中保留全部JSONL记录，内存中只保留最近32条；独立总计数不随缓存淘汰而回退。捕获文件编号应使用总计数，不能使用最近记录列表长度。关闭文件时fsync并发布完整文件SHA256。启动拒绝覆盖，NaN/Infinity在写文件前拒绝。

`StabilityStats`常量内存累计全程峰值，不以最后一个读数代替全程极值。默认判定口径：

- 有完整3600秒运行及正常退出；包括实时识别，不能只显示空频谱；
- 首次有效遥测应在计时开始1秒内，此后最大遥测间隔10秒，结束前10秒内仍须有遥测；时间必须递增，丢失和非法样本不能静默跳过；
- 内存为该进程Linux `/proc/self/status` 的当前VmRSS；全程峰值减首次基线严格小于10,000,000字节；不是全机缓存，也不是进程历史最大RSS；
- 最高温度严格低于85°C，处理故障为0；零帧率不能判为通过；
- 记录噪声事件次数，但次数不自动等于物理干扰源数量；
- 合成3601条遥测能通过，提前停止、少量样本修改duration、恰好10 MB增长、恰好85°C和瞬时故障均不能通过。

这是离线判定器。真实监测程序必须先正确接入数据来源与计时口径，不能直接把现有300秒发布配置改成3600秒便声称完成长测。

## 恢复开发板后的剩余工作（尚未执行）

1. 用户报告Read成功后核对完整镜像路径、字节数、结构及SHA256；退出成像工具、安全弹出读卡器。在板卡断电状态插卡，接回UART和网线。先确认配置A（RX1A接20–512 MHz、TX1A空）再上电和接收，不沿用配置B授权。
2. 扫频板端脚本接入冻结位流的`axi_ad9361_adc_dma`原始快照通路，不能启动PL频谱/CFAR处理链做30.72 MSPS连续处理。使用现有DMA驱动及CMA在途隔离保护；保存IQ、LO/采样率/增益/RSSI读回及哈希。先短测核实I0/Q0布局、12位符号和边界保护，再扫配置A。
3. 任何退出路径均恢复3.84 MSPS、正常RF带宽与LO，TX保持89.75 dB并检查停止状态；DMA仍在途时不得释放其缓冲区。停用的PL支路状态与活动原始DMA状态分别记录，不将无活动PL链的状态当作连续宽带验收。
4. 增加显式长测入口，例如`monitor --stability`，保持普通monitor原有300秒上限。接入流式记录、全程遥测、周期性噪声采样及独立捕获计数；显示和识别必须保留，summary若仅用最近缓存须明确标注范围。短测验证退出/磁盘写满/异常后再运行真实一小时。
5. 全程基线从启动质量检查完成后计时；先取得有效初始帧率/内存，再严格执行一小时口径，不虚构计时0秒的有效帧率。将真实通路的故障位转换为判定器processing_status，保留原始寄存器证据。
6. 配置A结束后停止射频，提示用户换配置D并等确认，再扫描高段；两组分别绘图。最后恢复3.84 MSPS。
7. 板测结果JSON/SHA256、停止状态、人工观察完成后再判定F4。不覆盖X2连续全带宽FAIL，不将合成一小时遥测当作一小时实测。
