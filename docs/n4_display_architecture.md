# N4显示方案：SSD1963整行滚动与固定区

## 用户已确认的布局修正（2026-11-02）

用户明确选择“列表集中在右上固定区，更多目标分页显示，优先保证刷新速度”。该确认覆盖80_next第2节中右侧列表纵贯400行的旧布局。

|区域|坐标（右/下界不包含）|策略|
|---|---|---|
|频谱/门限|x0..560,y0..160|每显示帧重画560×160|
|信号列表|x560..800,y0..160|固定区，分页，内容改变时刷新|
|瀑布|x0..560,y160..400|每显示帧仅写一行560像素，整行硬件滚动|
|瀑布右侧|x560..800,y160..400|保持纯色空白，不放文字|
|状态栏|x0..800,y400..480|固定区，内容改变时刷新|

依据：本机正点原子LCD资料中的SSD1963_DS_V1.1.pdf，第34/35页0x33/set_scroll_area及图9-9，第39页0x37/set_scroll_start。滚动区按完整行定义，不能只移动左侧560列而保持同高度的右侧列表。保留旧布局需每帧补刷240×240像素，会增加57600像素传输；用户已选择固定区布局以避免此开销。源文件SHA及渲染核查见本地logs/N4_lcd_scroll_reference.json和N4_ssd1963_page*.png，原厂PDF未修改。

## 存储/接口预算

- SSD1963自带帧存储，取消旧256KiB双页帧缓存。
- 上方列表240×160 + 底栏800×80合计102400像素，2bit调色板索引需25600字节；用32KiB AXI BRAM足够。调色板为背景/白/黄/青，文字逐像素带背景，避免旧字残影。
- 两份560点频谱行和两份560点门限行，用双时钟BRAM与请求/确认握手交换；屏幕绘制期间生产者不得覆盖当前读bank。
- 显示帧率与DSP帧率分开统计。忙时整帧丢弃显示快照，不回压连续DSP链；必须配对相同帧的谱线与门限，不能把两帧混画。
- BUS_PHASE默认25，使用原已验证的初始化ROM；降低档位仍需按80_next由用户目视确认。未实测前不宣称15fps已经达成。
- 全局滚动参数TFA=160、VSA=240、BFA=80，相加必须为480；0x36的行列交换位必须保持符合手册滚动模式的值。
