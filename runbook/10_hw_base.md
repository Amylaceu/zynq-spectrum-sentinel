# P1 ADI HDL 移植到正点原子 Z20（基础位流）

> 目标：得到 `fmcomms2_z20` 基础工程，包含 AD9361 接口、ADI RX/TX DMA、AXI Quad SPI、AXI GPIO，时序收敛，并导出 `.bit`、`.hwh`、`.xsa`。
> 原则：**不修改 `third_party/hdl` 中的任何 ADI 文件**。所有 Z20 相关文件放在 `src/hw/fmcomms2_z20/`（覆盖层），构建前由同步脚本复制到 `third_party/hdl/projects/fmcomms2/z20/`。

---

## P1.0 时钟与关键决策（本阶段确定，之后保持不变）

**运行环境**：目标设备 PowerShell，已执行 `. .\tools\env.ps1`；Vivado 版本见 `$env:VIVADO_VER`。ADI hdl 分支已在 P0.6 中根据 Vivado 版本选定（2025.2 用 `hdl_2026_r1`，2026.1 用 `main`）。
**本阶段只编译，不需要开发板。**
**参考**：如果 G0 中用户提供了自己已经能用的工程（`board/overlay/user_existing/`），可以和本阶段生成的引脚约束、`ADC_INIT_DELAY` 互相对照。

| 项目 | 取值 | 依据 |
|---|---|---|
| 器件 | `xc7z020clg484-2` | 核心板原理图 U1 标注 |
| 时钟分配说明 | 以下 FCLK 分配**取代** `design_plan.md` 6.1 节中的写法（为与 ADI 原工程保持一致，200 MHz 放在 FCLK1） | — |
| FCLK0 | 100 MHz：AXI-Lite、DMA、`sys_cpu_clk` | 与 ADI 一致 |
| FCLK1 | 200 MHz：IDELAYCTRL（`sys_iodelay_clk`） | 与 ADI zed 一致 |
| FCLK2 | 150 MHz：自研 DSP 时钟 `dsp_clk`（P4 才启用） | 总方案 6.1 节 |
| FCLK3 | 不使用（显示像素时钟由 `axi_dynclk` 产生） | — |
| AD9361 SPI | **AXI Quad SPI（PL）**，不用 PS SPI0 EMIO | PYNQ 镜像的设备树没有使能 PS SPI，Linux 还可能关闭未使用的时钟；用 PL 的 AXI SPI，用户态通过 MMIO 就能直接访问 |
| AD9361 GPIO | **AXI GPIO（PL）**：ch1 输出 16 位，ch2 输入 8 位 | 同上 |
| ADI DMA | `axi_dmac`，**关闭 SG（scatter-gather）**，RX 走 HP1、TX 走 HP2 | 用户态驱动更简单 |
| 接口电平 | Bank33/34：`LVDS_25` + `DIFF_TERM TRUE`；单端信号 `LVCMOS25` | 两个都是 HR Bank，VCCO = 2.5V |

**AXI GPIO 位定义（ch1 输出，地址 +0x0000）**——之后的 no-OS 平台层和 Python 驱动都按这张表实现：

| 位 | 信号 | 说明 |
|---|---|---|
| 0 | `gpio_resetb` | AD9361 RESETB，低电平有效 |
| 1 | `gpio_sync` | 多片同步（本设计不用，保持 0） |
| 2 | `gpio_en_agc` | AGC 使能引脚 |
| 3–6 | `gpio_ctl[3:0]` | CTRL_IN |
| 7 | `up_enable` | 引脚控制模式下的 ENABLE |
| 8 | `up_txnrx` | 引脚控制模式下的 TXNRX |
| 9–15 | 保留 | — |

ch2 输入，地址 +0x0008：bit[7:0] = `gpio_status[7:0]`（CTRL_OUT）。

## P1.1 生成 Z20 PS7 预设（从正点原子 hwh 中自动提取）

**前置条件**：P0.7（已解压 `vendor/atk/pynq_ref/base/ready_to_test/base.hwh`）
**产出文件**：`tools/gen_ps7_preset.py`、`src/hw/fmcomms2_z20/z20_ps7_preset.tcl`

`tools/gen_ps7_preset.py`：
```python
"""从正点原子 PYNQ base.hwh 中提取 Z20 的 PS7 配置（DDR、MIO、外设），生成 Tcl 预设文件。"""
import re, sys, pathlib

src = pathlib.Path(sys.argv[1]).read_text(encoding="utf8", errors="ignore")
i = src.find('MODTYPE="processing_system7"')
blk = src[i:src.find("</MODULE>", i)]
params = re.findall(r'<PARAMETER NAME="(PCW_[A-Z0-9_]+)" VALUE="([^"]*)"', blk)

# 只保留"板级"参数：DDR、MIO 电气属性、Bank 电压、外设使能与 IO 分配、晶振
keep = re.compile(
    r"^PCW_(UIPARAM_DDR_|PRESET_BANK|MIO_\d+_(IOTYPE|PULLUP|SLEW|DIRECTION)$|"
    r"(SD0|SD1|QSPI|ENET0|UART0|UART1|USB0)_|"   # 不带 I2C0/1（正点原子用 EMIO）、CAN、SPI，避免在 BD 中出现悬空的 EMIO 端口
    r"SINGLE_QSPI|GPIO_MIO_GPIO_ENABLE|CRYSTAL_PERIPHERAL_FREQMHZ|APU_PERIPHERAL_FREQMHZ|"
    r"SDIO_PERIPHERAL_FREQMHZ|QSPI_PERIPHERAL_FREQMHZ|ENET0_PERIPHERAL_FREQMHZ|EN_DDR)")
# 只读或派生参数，设置了也会被忽略或产生告警，直接排除
drop = re.compile(r"(ACT_|_DIVISOR|_CLKSRC|FREQMHZ_ACT|_HIGHADDR|_BASEADDR|_ISUSED|_INTR|_PCLK|_GRP_FBCLK)")

lines = ["# Auto-generated by tools/gen_ps7_preset.py from ATK base.hwh. DO NOT EDIT.",
         "proc z20_apply_ps7_preset {ps7} {",
         "  set cfg [dict create]"]
n = 0
for k, v in params:
    if keep.search(k) and not drop.search(k) and v not in ("", "<Select>", "&lt;Select>"):
        v = v.replace("&lt;", "<").replace("&gt;", ">").replace("&amp;", "&")
        lines.append(f"  dict set cfg CONFIG.{k} {{{v}}}")
        n += 1
lines += [
    "  # 逐项设置：某一项失败时只打印告警，不中断构建",
    "  dict for {k v} $cfg { if {[catch {set_property $k $v [get_bd_cells $ps7]} err]} { puts \"WARN ps7 $k: $err\" } }",
    "}"]
pathlib.Path(sys.argv[2]).write_text("\n".join(lines) + "\n", encoding="utf8")
print(f"wrote {n} params -> {sys.argv[2]}")
```

**命令**：
```powershell
. .\tools\env.ps1
New-Item -ItemType Directory -Force src/hw/fmcomms2_z20 | Out-Null
python tools/gen_ps7_preset.py vendor/atk/pynq_ref/base/ready_to_test/base.hwh src/hw/fmcomms2_z20/z20_ps7_preset.tcl
```

**验收命令**（以下关键参数必须出现在生成的文件中）：

## P1.2 编写 Z20 系统框图脚本 `z20_system_bd.tcl`

**前置条件**：P1.1
**参考**：`third_party/hdl/projects/common/zed/zed_system_bd.tcl`
**产出文件**：`src/hw/fmcomms2_z20/z20_system_bd.tcl`

**要求**：在 ADI zed 版本的基础上做以下修改。代理应先完整阅读 zed 版本，再按下面的清单逐项改写：

| zed 原有内容 | Z20 版本的处理 |
|---|---|
| `PCW_IMPORT_BOARD_PRESET ZedBoard` | 删除；改为 `source z20_ps7_preset.tcl` 后调用 `z20_apply_ps7_preset sys_ps7` |
| FCLK0 = 100、FCLK1 = 200、`USE_FABRIC_INTERRUPT`、`IRQ_F2P_INTR`、`IRQ_F2P_MODE REVERSE`、`USE_S_AXI_HP0` | **保留**（必须放在预设之后设置，确保不被覆盖） |
| `PCW_GPIO_EMIO_GPIO_ENABLE 1`、`IO 64` | 保留（不使用，但避免改动 ADI 脚本中对 `gpio_i/o/t` 端口的引用） |
| SPI0/SPI1 EMIO | **删除**，同时删除 `spi0_*`、`spi1_*` 外部端口 |
| `PCW_USE_DMA0/1/2`、`axi_spdif_tx_core`、`axi_i2s_adi`、`sys_audio_clkgen` | 删除（音频在 P4 中用自研 I2S 实现） |
| `axi_hdmi_*`、`axi_hdmi_dma` | 删除（显示在 P4 中用 VDMA + rgb2lcd 实现） |
| `axi_iic_main`、`sys_i2c_mixer`、`iic_mux_*` | 删除 |
| `axi_iic_fmc` | 保留（读取 FMCOMMS3 的 EEPROM）；对外端口名为 `iic_fmc` |
| `axi_sysid_0`、`rom_sys_0` | 保留 |
| `otg_vbusoc`、`sys_logic_inv` | 删除；`USB0_VBUS_PWRFAULT` 接常量 0 |
| `sys_concat_intc` | 保留 16 路；In11 接 `axi_iic_fmc`，其余接地 |

在文件末尾追加：
```tcl
# Z20 additions: AXI Quad SPI + AXI GPIO for AD9361 control (user-space MMIO friendly)
ad_ip_instance axi_quad_spi axi_ad9361_spi [list \
  C_SPI_MODE 0 C_NUM_SS_BITS 1 C_SCK_RATIO 16 C_USE_STARTUP 0 C_FIFO_DEPTH 16 C_NUM_TRANSFER_BITS 8]
ad_ip_instance axi_gpio axi_ad9361_gpio [list \
  C_IS_DUAL 1 C_GPIO_WIDTH 16 C_ALL_OUTPUTS 1 C_DOUT_DEFAULT 0x00000000 \
  C_GPIO2_WIDTH 8 C_ALL_INPUTS_2 1]
ad_connect sys_cpu_clk axi_ad9361_spi/ext_spi_clk
create_bd_intf_port -mode Master -vlnv xilinx.com:interface:spi_rtl:1.0 spi_ad9361
ad_connect spi_ad9361 axi_ad9361_spi/SPI_0
create_bd_port -dir O -from 15 -to 0 ad9361_gpio_o
create_bd_port -dir I -from 7 -to 0 ad9361_gpio_i
ad_connect ad9361_gpio_o axi_ad9361_gpio/gpio_io_o
ad_connect ad9361_gpio_i axi_ad9361_gpio/gpio2_io_i
ad_cpu_interconnect 0x41E00000 axi_ad9361_spi
ad_cpu_interconnect 0x41200000 axi_ad9361_gpio
ad_cpu_interrupt ps-10 mb-10 axi_ad9361_spi/ip2intc_irpt
```

> **代理注意**：`ad_cpu_interconnect`、`ad_connect`、`ad_ip_instance`、`ad_cpu_interrupt` 都定义在 `third_party/hdl/projects/scripts/adi_board.tcl`。使用前先确认它们在 `hdl_2026_r1` 分支中的参数格式，尤其是 `ad_cpu_interrupt` 的 `ps-N mb-N` 写法。

## P1.3 复制并修改 fmcomms2 公共框图（关闭 SG）

**产出文件**：`src/hw/fmcomms2_z20/fmcomms2_z20_bd.tcl`
**来源**：复制 `third_party/hdl/projects/fmcomms2/common/fmcomms2_bd.tcl`

修改项：
1. `axi_ad9361_adc_dma` 和 `axi_ad9361_dac_dma`：`CONFIG.DMA_SG_TRANSFER 0`。删除所有 `m_sg_axi` 相关的 `ad_connect` 和 `ad_mem_hp*_interconnect` 连接。
2. 删除 `util_ad9361_tdd_sync` 实例及其连线，`axi_ad9361/tdd_sync` 接常量 0（参考原 zed 工程 `system_bd.tcl` 中的 `TDD_DISABLE 1`）。
3. 保持地址不变：`axi_ad9361` 0x79020000、`adc_dma` 0x7C400000、`dac_dma` 0x7C420000。
4. 保持中断不变：adc_dma → ps-13，dac_dma → ps-12。

## P1.5 顶层 `system_top.v`

**产出文件**：`src/hw/fmcomms2_z20/system_top.v`
**参考**：`third_party/hdl/projects/fmcomms2/zed/system_top.v`

在 zed 版本的基础上：
- **删除**端口：`gpio_bd`、`hdmi_*`、`i2s_*`、`spdif`、`iic_mux_*`、`otg_vbusoc`、`spi_udc_*`、`gpio_muxout_*`。
- **保留**端口：`ddr_*`、`fixed_io_*`、`rx_*`、`tx_*`、`txnrx`、`enable`、`gpio_resetb`、`gpio_sync`、`gpio_en_agc`、`gpio_ctl[3:0]`、`gpio_status[7:0]`、`spi_csn`、`spi_clk`、`spi_mosi`、`spi_miso`、`iic_scl`、`iic_sda`。
- GPIO 改为单向连接，不再使用 `ad_iobuf`：
```verilog
  wire [15:0] ad9361_gpio_o;
  assign gpio_resetb = ad9361_gpio_o[0];
  assign gpio_sync   = ad9361_gpio_o[1];
  assign gpio_en_agc = ad9361_gpio_o[2];
  assign gpio_ctl    = ad9361_gpio_o[6:3];
```

- SPI 接口（AXI Quad SPI 的 `spi_ad9361` 接口展开为 `*_io0_o`、`*_io1_i`、`*_sck_o`、`*_ss_o` 等）：
```verilog
    .spi_ad9361_io0_i (1'b0),
    .spi_ad9361_io0_o (spi_mosi),
    .spi_ad9361_io0_t (),
    .spi_ad9361_io1_i (spi_miso),
    .spi_ad9361_io1_o (),
    .spi_ad9361_io1_t (),
    .spi_ad9361_sck_i (1'b0),
    .spi_ad9361_sck_o (spi_clk),
    .spi_ad9361_sck_t (),
    .spi_ad9361_ss_i  (1'b1),
    .spi_ad9361_ss_o  (spi_csn),
    .spi_ad9361_ss_t  (),
```
- `.up_enable (ad9361_gpio_o[7])`、`.up_txnrx (ad9361_gpio_o[8])`、`.ad9361_gpio_i (gpio_status)`、`.ad9361_gpio_o (ad9361_gpio_o)`。
- IIC：`.iic_fmc_scl_io (iic_scl)`、`.iic_fmc_sda_io (iic_sda)`。
- `gpio_i`、`gpio_o`、`gpio_t`（PS EMIO）：`gpio_i` 接 0，另外两个悬空。

> 端口名以 Vivado 生成的 `system_wrapper.v` 为准。第一次构建失败时，打开 `fmcomms2_z20.gen/sources_1/bd/system/hdl/system_wrapper.v` 核对端口名后再修改。

`tools/sync_hw.ps1`：

```powershell
param([string]$Proj = "fmcomms2_z20")
# fmcomms2_z20 -> projects/fmcomms2/z20 ；sentinel_z20 -> projects/fmcomms2/sentinel_z20
```

**排错**：

| 现象 | 处理 |
|---|---|
| `[DRC BIVC-1] Bank 33/34 ... incompatible IOSTANDARD` | 检查是否有 LVCMOS33 约束落在 Bank33/34 上；正点原子 XDC 中的 sys_clk（L18）、KEY 等**不要**加入工程 |
| `[Place 30-...] Clock placement` / IDELAYCTRL 报错 | 确认 `axi_ad9361/delay_clk` 接到 200 MHz（FCLK1），并且 IDELAYCTRL 覆盖了 Bank33 和 Bank34（ADI 核内部会自动复制 IDELAYCTRL；若报错，把 `axi_ad9361` 的参数 `IODELAY_CTRL` 设为 1） |
| `rx_clk_in_p` 不在时钟能力引脚上 | Y18 是 MRCC，不应该出现这个错误；若出现，说明管脚 P/N 写反了，检查 LA00_CC |
| hold 违例 | ADI 的 `auto_timing_fix_xilinx.tcl` 会自动处理；若仍失败，把策略改为 `Performance_ExplorePostRoutePhysOpt` |
| `system_wrapper` 端口不匹配 | 按 P1.5 的说明核对 `system_wrapper.v` 后修改 `system_top.v` |
