## J2 上位机讲解模式与观感打磨（P0，本阶段重点）

### 2.1 上位机 → 常驻服务的直连
- 场景切换只走 hostlink（TCP 9000）的 `scene <id>`，**不再用 SSH**。板端收到命令后立即回 `scene_ack`，就绪后回 `scene_ready`（带板内耗时），失败回 `scene_error`（带原因）。
- 上位机启动后**自动连接**上次的地址；断线时每 2 s 自动重连，顶栏显示"重连中"；重连后自动同步当前场景。
- **端到端指标（从按下按钮到上位机收到 `scene_ready`，P90）**：

| 场景 | 目标 |
|---|---|
| fm、perf、idle、tone | ≤ 1.5 s |
| listen | ≤ 3.0 s（并且喇叭出声） |
| check | ≤ 3.0 s |
| pano | ≤ 1.0 s 出现参考全景 |
| ota_replay | ≤ 1.5 s |

### 2.2 讲解模式（快捷键 P，或用启动参数 `--present`）
1. **场景条**（底部，高 72 px，按讲解顺序排列）：
   `① 自检  ② 全景  ③ 监测识别  ④ 收听广播  ⑤ 精度验证  ⑥ 空口实测  ⑦ 性能`，以及红色 `■ 停止`。
   - 当前场景高亮，下一个场景显示淡色提示；状态分为就绪、启动中（按钮内转圈）、不可用（灰色，悬停显示原因）。
   - ④ 旁边有一个小下拉框选电台，默认是 config 中的第一个。
2. **按键**：`1–7` 直接进入；`→`/`PageDown`/空格是下一个；`←`/`PageUp` 是上一个；`Esc` 停止。**普通翻页笔可以直接用**。
3. **切换效果**：
   - 按下后：孪生画面上方出现 1 行"正在切换到：③ 监测识别…"，按钮转圈；
   - 就绪后：屏幕中央出现大标题横幅（48 px，例如"③ FM 广播实时监测与自动调制识别"，副标题一句话），1.5 s 后淡出；
   - 左右两栏**自动切到对应页面**（见 2.3），切换带 150 ms 淡入；
   - 超过目标时间 2 倍还没就绪：横幅变成黄色"该场景暂未就绪 [重试] [播放兜底]"。
4. **双窗口**：
   - **投影窗口**（F11 全屏，拖到投影或副屏）：只显示孪生画面、两侧面板、横幅和场景条；所有字号 × 1.25；隐藏开发用按钮；
   - **讲解者窗口**（笔记本屏幕）：场景条 + 当前场景的提词（取自 `tools/host/scenes.yaml`，与讲解稿一致）+ 本段建议时长与已用时间（绿 → 黄 → 红）+ 总计时（目标 4:00）+ 板端状态灯（连接、射频、音频、温度）。
   - 只有一块屏时，讲解者面板收成右下角半透明浮窗，可以拖动、可以隐藏（快捷键 H）。
5. **开场**：讲解模式启动时自动执行 ① 自检。预检中的"网络 RTT"由上位机补充；全部通过后横幅显示"系统就绪"。

## J3 新场景：精度验证与空口实测回放（P0）

   - 全程顶栏和孪生画面都显示 **`实测数据回放 · F3 空口采集 2.45 GHz`**，**不发射**，TX 保持 89.75 dB。最终显示的准确率必须与 `f3_evaluation_r1` 一致（在相同注噪参考下），讲稿引用的数字以此为准。

### v8.2 修改要求
**A. 布局**：13 张卡一屏放下不滚动。卡片改成一行（编号 + 名称 + ▶ + ■ + 状态灯），说明文字放到悬停提示里；两个分组标题都可见。
**B. 中间区域**：应用卡片去掉空坐标轴和顶部小频谱，结果表格、列表、进度条放大占满；FPGA 卡片保持"频谱 + 瀑布"。
**C. 对比表**：切换卡片时清空，只显示本卡数据。各卡的对比项：
| 卡 | 对比表内容 |
|---|---|
| F0 | 4 路 PN 错误 0、失步 0、检查时长 |
| F8 | 电台、导频突出度、播放样本、下溢 |
| F10 | CPU 用时（ms）、FPGA 用时（ms）、倍数（大号） |
| F11 | 扫描范围、段数、用时、最强频点 |
| F12 | 电台、投票结果、10 次中 FM 次数 |
| F13 | 样本数、十类准确率、八大类准确率、与参考一致 |
| F14 | 信道数、网络数、有效信标数、用时 |
**D. 屏幕文字**：状态一律中文短词（就绪 / 运行中 / 完成 / 未通过 / 已恢复）；所有口径说明、限制说明收进卡片右上角 ⓘ 悬停提示，内容保持如实；"目标未达"之类的验收结论只写在报告和 STATUS，主界面不显示。顶栏帧率在 LCD 不刷新时显示"—"。
**E. F10**：大号显示"CPU 15.8 ms │ FPGA 0.68 ms │ 约 23 倍"，ⓘ 中说明两者口径不同。
**F. F11**：
- 全景图加频段标注色带：FM 广播 88–108、航空 118–137、业余 144–148、对讲/专网 400–470 等；
- 结果分两列：①"FM 广播段最强 5 个"②"全频段最强 5 个"；
- 对 300–420 MHz 的窄尖峰，用 F1 的现场数据判断是否为板载杂散，如果是，就在列表上标注"疑似板内杂散"；
- 用已有扫描参数（每段帧数、切换稳定时间）做 1 轮提速，不能出现覆盖缺口；做不到就保持约 34 秒，显示剩余时间。
**G. F12**：
- 对 F8 搜到的全部候选电台各跑 10 次，把 ≥ 9/10 为 FM 的电台设为默认；
- 一个都不合格时，F12 从左栏移入"工具与导出 → 诊断"，左栏改为 12 张卡；
- 无论哪种情况，主界面都不显示单帧结果。
**H. F14 流水化（最重要）**：
1. 板端采集一结束（约 63 s），立即恢复 3.84 MSPS / LO 96.05 MHz 并读回，然后弹出换天线框："采集完成，请把 RX1A 换回 20–512 MHz 磁吸天线"。确认后，接收卡片马上解锁。
2. 电脑端解码在后台继续，F14 卡片显示进度。解码完成后，状态灯变绿并显示"结果就绪"，点卡片查看结果，**不自动抢占当前画面**。
3. 不依赖天线的卡片（F0、F2、F10、F13）任何时候都不被天线锁定。逐一核实它们确实不使用 RX 天线输入，不是的就仍然锁定。
4. 开场接法为"W"：TX1A 上的 2.4 GHz 胶棒拧在 RX1A，TX1A 空着，磁吸天线放在旁边。
**I. 发布定稿（J1）**：
- 板端：`release/v3` 或 `j8_final`，`~/start_demo.sh` 指向它，v2 保留回退；
- 电脑端：重新打包 SentinelHost.exe（含 Wi-Fi 解码调用 MATLAB 的路径配置），在演示笔记本上从双击到可操作 ≤ 60 s；
- 写清楚演示笔记本上 MATLAB / WLAN Toolbox 的检查方法。
**J. SD 检查**：正常关机后检查文件系统（只读检查，看 dmesg 中有没有 ext4 错误），结果写进 STATUS，然后提醒用户做整卡备份。
**L. 与板上 LCD 对比（用户新增要求）**：讲解时要让评委对照板上的 J22 LCD 看。
- FPGA 卡片（F1、F2、F4、F5、F6、F7）和 F8 运行时，LCD 实时显示同一组频谱和瀑布；
- 每张卡启动后，LCD 的 PS 区（右侧 240×400、底栏 800×80）都要显示**卡片编号、名称和 1 个关键数字**，例如"F5 CFAR GO 目标 3""F2 TONE 0 BIN""F10 23X""F14 WIFI CAP 45%""F13 AMC 83.4%"。只用已有 ui_v3 的文字和卡片接口绘制，不改 `lcd_x5.py` 和 `twin.py`；
- 不用 LCD 的卡片（F0、F10、F11、F13、F14），LCD 也要显示当前功能名和进度/结果，不能黑屏或停在旧画面；
- 上位机中间区加"对照 LCD"切换（快捷键 T），一键切到 J22 数字孪生，再按一次切回；数字孪生 PS 区与 LCD 逐像素一致；
- 验收：每张卡启动后拍 LCD 照片或抓孪生画面 1 张，确认卡片编号和关键数字在 LCD 上可见。
**K. 验证**：每处修改在真板上验证；每张卡 启动 → 停止 1 次，F0 → F14 连续切换一遍。不按讲稿彩排，不修改讲稿和操作手册（用户要求只解决问题）。
