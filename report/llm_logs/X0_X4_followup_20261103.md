# X0–X4 第二轮优化协作记录

- 用户要求：板卡保持上电，继续优化 X0–X4；已有天线配置 A，不需要人工换线。
- 执行范围：接续正在运行的 X2 整链仿真和配置流水局部时序审计，复核 X4 本地同步 CPU 实验，整理可跨设备复核的代码和证据。未启动 RF、未加载位流、未修改 third_party/vendor 或 X5 代码。
- X4 结果：显式 NativePredictor 后端通过 260 段完整输出及 36 个核心用例等价验证；P95 从 126.029 ms 降至 98.456 ms，仍有 3/150 次超过 100 ms。原模型、准确率失败及正式 FAIL 不变，默认 Predictor 不切换。
- X2 结果：maskpipe/cfgpipe 各 18 组黄金向量通过；寄存器边界 WNS 分别 −0.291/−0.147 ns，对照 −0.311 ns。没有夸大为整机通过。maskpipe 整链 30.72 MSPS 下 SAMPLE_DROP=0、FRAME_DROP=4，首 8192 功率字精确一致；cfgpipe 未进行此整链测试。
- 错误与纠正：证据汇总程序最初把资源报告所有行当成表格，触发 IndexError；修正后发现寄存器行在两节重复出现，改为允许数值相同的重复行、拒绝缺失或冲突值。两次失败均发生在封存输出生成前，未删除或覆盖历史测量。
- 验证：已有 280 项 PS/工具回归通过；汇总独立重算耗时、解析原始时序/资源报告、检查源文件 SHA256、核验 79 文件 ZIP manifest。
