# M-A 阶段检查点：X0–X3

## 用户目标与执行边界

用户要求以现有 Z20/AD9361/J22 LCD 尽快推进完整作品，无衰减器。X2 整机时序失败后，用户明确要求优先推进后续功能、最后优化时序；不将未经时序通过的位流上板。配置 A 分步骤由用户确认，X3 仅接收授权有效。

## 协作中的纠正

1. X0 完成 N4 改动核对/提交、SD 整卡备份、温度和默认 phase=3；曾因网络/启动异常转串口核实并按安全流程备份，不把超时当正常运行。
2. X1 保留三轮失败；用户授权追加 GUARD=8 一轮。容量告警降至 2.86%，95.8 MHz 检出 73.58% 仍未达到 80%；95.45 MHz 高频出现仅作为补充，不冒充原目标。
3. X2 有完整仿真与实现归档，r2 WNS−0.709 ns/WHS−0.058 ns；四档宽带没有上板。用户选择延期，继续使用通过时序的 v1b、3.84 MSPS。
4. X3 数字首轮因额外目标触发过严断言停止，保留失败；改为确认已知主峰、逐帧计数和标记匹配后完成 1000 次。接收首轮把初始化历史锁存带入窗口，立即停止；复测记录清零前后状态，30 秒零溢出，未在测试中清零。
5. 独立分析纠正性能口径：组合吞吐 22.75 倍不等于 FFT 快 22.75 倍；整帧时延 629.90 µs 未达 200 µs；推算 96.83 µs 不能称独立 CFAR 实测。历史 CPU 占用没有记录，明确标 NOT_MEASURED。

## 当前成果与限制

PL 频谱/CFAR、SSD1963 直驱约 49.45 fps 可用，G1 原始 NPZ 再核验通过。测量 JSON/SHA256、原始失败轮次、精确源代码快照、表图与可执行分析器已归档。新增防误验收测试拒绝少帧、重复标记、错误计数、错误黄金值、溢出和哈希篡改。

这是保留 X1/X2/X3 原指标失败的阶段收口，**不是 M-A 全指标通过**，也不意味着调制识别、信道捕获、耳机、空口评估已完成。按用户优先功能要求继续 X4，未达标项留待后续优化。
