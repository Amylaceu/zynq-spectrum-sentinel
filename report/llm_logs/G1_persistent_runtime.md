# G1 常驻演示运行时协作记录

## 任务与约束

依据 G_showcase 的 G1，在冻结100MHz/3.84MSPS位流、模型和CFAR参数的条件下，减少演示重复初始化，保留逐段安全停止与隔离回退，并审计实际播放录音的可行性。配置A由用户确认，仅接收；无发射、无新增板端软件依赖。

## 关键设计与纠正

对照原Session所有权、射频驱动锁及GPIO复位行为，确认“每段GPIO归零”与“整组仅初始化一次射频”不可同时成立。实现显式依赖注入，缓存overlay/DMA对象、模型和段入口，射频仍在安全复位后重新初始化。DMA失效后拒绝复用；每段读回TX衰减和GPIO/SRC/audio状态。

音频冻结控制接口缺少实际播放PCM读取路径。未把稀疏IQ重解调或模拟音频当作播放录音；请求录音时明确记录UNSUPPORTED_NO_PLAYBACK_PCM_READBACK，不创建替代WAV。该要求继续列为未达标。

首次验收后补充内容起点时间戳、异常堆栈与停止请求传播，第二次部署核验最终代码。保留冷启动首遍，分别判定功能完成和量化指标，不删掉较慢数据。

## 测试与用户反馈

完整PS/工具回归635项通过、18项略过；后补停止传播分支的针对性14项通过、18项略过。证据校验与运行时11项通过，包括损坏SHA256、错误引用、越界路径、无计时证据、失效DMA及信号恢复。各批测试范围有重叠，不累加通过数量。

用户对第一轮三遍A组明确确认：“显示与声音均正常”。该反馈仅证明实际显示和听音观察，不证明未达到的时长、切换和WAV指标。B组当前只作离线测试，G5换天线确认后再实测。

初次临时启动脚本因未加入src/ps导入路径而在访问板卡前失败，修正路径后才启动第二轮；未计为射频实验或掩盖为成功。发布包哈希及板端回退目录保留。

最终量化结果与证据路径见docs/g1_persistent_runtime.md、runbook/STATUS.md及board/measurements/g1_acceptance_final.json。
