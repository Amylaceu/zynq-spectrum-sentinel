# Y2 第二轮硬件实现与接收闭环协作记录

## 任务与输入

用户要求按95_final继续功能闭环，禁止重训及追加X1–X4调参；确认买不到功分器，
已修改方案。阅读实际AGENTS/STATUS/95_final和天线指南，以A/B分组代替配置E。
原PFB第三轮仿真与CFAR第二轮仿真PASS，不重新计算轮次。

## 执行与纠正

- 读取后台整机构建及独立审计：均退出0，WNS+0.092ns、WHS+0.037ns。
- 依赖检查错误地对namespace模块Path(None)，修正后再部署；旧失败日志保留。
- PYNQ2.7的BRAM不在ip_dict，第二次绑定失败。修正兼容后第三次完成120秒实采。
  随后加强主机代码为接受文件哈希+HWH MEMORY地址/大小校验；加强版未倒签到实测。
- 最初统计脚本要求perf.status=0，误拒状态4。依据perf_mon RTL只把bit0/1作为
  故障，保留bit2..4状态并拒未知高位。测试覆盖正常状态4、溢出、错误和非法值。
- 发现手工r3 prebuild清单误混软件修订与硬件构建。保留原字节，并加独立runtime
  manifest机制链接原r2；部署工具拒绝与acceptance不匹配的实现标签。
- 源码/数据不覆盖失败证据，不改第三方目录。未向GitHub推送。

## 结果与限制

229项回归通过。194份捕获逐包验证；中位时延481.181ms，中位显示28.992fps，
已知95.8MHz五票FM为3/9，Y2自动指标FAIL。95.45MHz身份未知，不计入真值。
硬件539文件归档含原始报告/日志/DCP和产物，JSON+SHA256追溯。
三轮板测机会已使用，不无限调参。Z2和目视待完成，后续Y3须耳机人工确认。
