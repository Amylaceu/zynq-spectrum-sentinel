# 展示天线取舍与验证记录

日期：2026-11-04。

目标：在冻结100MHz/3.84MSPS基线下比较S1、S2，尽量使展示中途不用换天线。需求明确禁止更改位流、训练模型或调整检测参数。

工作分配：用户完成换线、确认手机热点开关及实际听音；软件完成30秒FM质量门控检查、有限原始IQ采集、单音空口标定、独立复算、退出状态读回及摘要保存。每次候选发射均获得单独确认，凭据仅经标准输入传递。

发现与纠正：数字音频计数正常不能证明广播可听。S2计数与FIFO检查通过，但导频不满足门槛、放音0秒，用户也确认无广播，保留FAIL。空口脚本执行PASS与25dB目标分别判断：S1仅17.721dB，仍记FAIL；S2达到29.472dB时停止增加功率，衰减50dB。该单音比不等于调制准确率或校准射频SNR。

热点对照中关闭状态也有环境突发；顺序有限快照、AGC变化及部分幅度边界诊断限制归因。两候选均不宣称手机或SSID识别通过，不凭一般能量变化虚构协议结果。S2对照中有窗口中位能量小幅增加，仍不足以证明设备身份。

取舍：依照已有降级规则选择FM合格的S1，空口展示使用明确标REPLAY的记录；素材封装与场景接入留待后续步骤。当前实物恢复仍由用户确认。证据总索引为board/measurements/i0_antenna_s.json，全部来源附SHA256；源码未修改第三方及冻结显示驱动。
