# F3 空口闭环与演示协作记录

### [2026-11-04] 冻结硬件后的功能闭环及证据收尾

**提示词**：用户要求按99_finish执行F0–F6，固定100MHz/3.84MSPS基线，不重新训练、调CFAR或综合布线。用户确认实际接线为两根2.4GHz折叠胶棒直插TX1A/RX1A，间距约2–3cm，并要求继续推进；演示目视反馈为“画面没问题”。

**模型回答（摘要）**：按更新的B-直插方案限制到2.45GHz及40dB衰减下限，复用已验收位流，提供独立发射库、看门狗、十类波形、捕获及数字注噪评测，并接入正式demo B调度入口。发送真值SENT与冻结模型预测分开显示，不把真值填入预测列表。

**验证**：500个循环波形窗口在数字注噪参考10dB下十类83.4%、八大类86.0%；原始IQ、混淆矩阵和曲线均有SHA256。第二次正式演示连续3遍/12段完成，104文件传输校验通过，最低36.563fps、最高65.950°C；发射段最低衰减40dB、最高RSSI−58.5dBm。退出时最大衰减恢复、ENSM=ALERT，GPIO/SRC/audio均0。605项PS/工具回归通过、18项略过，日志F3_final_regression_env.log。最终汇总见board/measurements/f3_acceptance_final.json。

**纠错**：首次B组性能段被历史ADC溢出状态中止，退出SRC模式位也未全部清零。修复限定于PS：重新加载同一冻结位流、RF保持复位时清除启动历史状态、运行中故障检查不变，并在释放硬件锁前归零SRC。保留第一次FAIL原始结果。第一次全量回归因Windows Tcl环境和输出捕获失败，显式设置实际Tcl/Tk目录并关闭pytest输出捕获后通过；没有启动Vivado构建。收尾复核特别区分独立发射库e89a…d271和正式接收库b329…1683，避免交接时混用。

**未达标及边界**：八大类未达90%，宽带标定三轮未达25dB，最高注噪档单音只命中15/30，Pd/Pfa未校准；每遍段耗时156–160秒超约2分钟目标。捕获窗口不代表独立波形试验，后加数字噪声不等于已知RF输入SNR。整体F3记FAIL，功能PASS；人工反馈仅覆盖实际观察画面，不扩写为完整三遍逐项确认。不追加调参或重构。

**沉淀**：正式入口、独立发射库、清理读回、只读结果收集和源文件/数据哈希形成可交接流程。DMA状态未确认空闲时保留缓冲区和所有权，不能以释放内存代替停机；脚本成功退出与工程指标通过分别判定。F4须先等待整卡备份和配置A人工确认。
