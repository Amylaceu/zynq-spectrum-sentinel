# Y3噪声诊断协作记录

用户反馈广播基本全是噪声，并授权接线不变继续优化。执行代理先对既有历史IQ与PFB数学模型离线对照，再在现有100MHz已审计位流上做两轮仅接收ADC/PFB快照和PN9/LCD开关对照。

关键纠正：不能以测试音出声、FIFO无下溢推断广播音质合格。噪声已存在于部分原始ADC IQ，而同一配置后续能恢复清楚导频；PN9四路0错误、LCD开关无单一对应关系，故只将问题定位到接收信号质量随时间变化，未声称确定具体干扰源。

优化：新增可选立体声导频质量门控、状态显示、真实放音区间及可复现诊断脚本，无新的综合布线。第一次门控板测发现采集前时间戳造成采样速率虚高，已修正，失败原件保留；第二次实际间隔正常但固定每秒样本数门槛不适用，补充真实时间覆盖检查，独立复核而不覆盖原FAIL。

用户确认短试听更清晰，后又确认稳定性测试中广播清楚、轻微底噪、无明显断音。最终300.0989秒链路、299.0467秒连续放音、最低40.3784fps、零下溢。初始质量确认静音不能计作连续出声，严格300秒出声尚未完全覆盖，保留Y3历史FAIL。85项针对性测试通过；所有测量JSON及其引用IQ/WAV均可校验SHA256。具体文件见docs/y3_noise_diagnosis.md。

用户要求下次提高音量，已记录偏好，未修改本轮−15dB设置。测试结束静音并关闭GPIO/SRC/audio，不断电，不发布GitHub，不修改third_party/vendor。
