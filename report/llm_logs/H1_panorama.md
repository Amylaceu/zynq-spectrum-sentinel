# 全景扫描与现场交互开发记录

用户要求彩排后置、优先功能。本轮保持冻结100MHz位流，不综合/布线、不训练、不调CFAR。按当前配置A授权先做有限快照扫描；用户随后确认已换配置D，才启动高频接收。

先保存55LO实测78.350秒与原始IQ。从10LO计时发现组合射频配置仅0.602秒，Welch2.757秒、压缩写盘4.153秒，因此优先缩减采样与落盘，不先引入fastlock。18MHz单步进数值规划出现750个DC缺口，改用9MHz且独立检查A/D覆盖；未用插值填补空白。

快速版为65536点、批量FFT、默认PSD-only、不压缩小数组。A两轮分别43.063/42.225秒，较原版约45%下降；10秒目标仍FAIL。保持150ms AGC等待及丢弃快照，不以删除稳定步骤换取虚假指标。4096点PSD逐段通过有界SSH流传送，Qt全景页显示暂态曲线；收齐结果和独立停止证据后校验SHA256才切换已验证画面。源码保持原孪生协议不变。

37项核心回归通过；二维码相关22项通过。二维码首次测试引用不存在的qapp fixture，第二轮改用既有QApplication初始化方式后通过，失败日志保留。二维码只展示局域网服务地址，不启动服务或声称路由器已连通。

D组用户实际观察为“逐段增加”，只记录这一观察，不扩大为缩放、稳定性或无线业务识别验收。仍需如实记录D结果、快扫、点击定点识别、独立带宽/增益模式读回及一小时稳定性不足。PC连续DMA与模型历史FAIL继续保留。
