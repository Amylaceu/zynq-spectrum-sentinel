## PS7 预设与工程入口

**提示词**：runbook P1.1–P1.4 要求从正点原子参考资料提取 PS7 配置，建立 Z20 基础 BD 和 ADI 工程覆盖层。

**模型回答（摘要）**：解析 HWH，筛选板级 PCW 参数，生成 Tcl；关闭 DMA SG，删除不需要的 HDMI/音频/TDD 接口，保留 AD9361 接口、DMA、Quad SPI、控制 GPIO 与 FMC IIC。

**出错与纠正**：直接按参数名逐条应用会在 Bank 电压仍为默认值时拒绝 1.8 V MIO。派生的 MIO_DIRECTION 也不应作为独立预设输入。改为先设 Bank 电压，再原子应用筛选后的 278 项参数。

**验证**：第二轮实际 Vivado Tcl 加载成功，8 项关键配置读回一致；核实 ADI 工程 API 中 p_device 的选择逻辑及 sys_zynq 的自动派生。关闭 SG 后无 m_sg_axi；仅将 TDD 输入接地，不误接输出。

**沉淀**：生成参数后必须实际创建 IP 并读回；语法正确不足以验证跨参数约束。

## 引脚核对

**提示词**：runbook P1.6 要求交叉核对底板、核心板及外设 XDC，禁止猜测硬件引脚。

**模型回答（摘要）**：核对 55 路外部信号的唯一性、Bank 电压类别及板载接口冲突，视觉检查底板第 2/15 页及核心板第 3/4 页。

**出错与纠正**：手册暂定的 FMC IIC 顺序不正确。底板 CN2 与核心板 Bank35 网络对应证明 SCL=G21、SDA=G20，已在覆盖层修正。

**验证**：`logs/P1.6_pincheck.txt` 记录映射、重复检查和源文件 SHA256；渲染图留存在本机日志目录。完整实现无 Bank 电压冲突 DRC。

**沉淀**：按网络名贯穿连接器、核心板连接器与 FPGA 球位，不根据名称相近或其他载板的 XDC 推断。

## 顶层绑定与完整实现

**提示词**：runbook P1.5/P1.8 要求核对生成 wrapper 的真实端口并构建位流。

**出错与纠正**：最初顶层按展开 SPI 端口连接 system_wrapper，但实际 wrapper 将 SPI 包为 IOBUF 端口。生成 BD 后发现不匹配，改为实例化底层 system BD，SPI 使用单向 I/O，仅 IIC 显式使用双向缓冲。此修正在主综合仍排队、尚未开始时同步到构建目录。

**验证**：逐项核对 60/60 命名端口；完整综合、实现与位流生成退出 0。布线后 WNS=+0.524 ns、WHS=+0.008 ns，无实际 ERROR。三项 bit/hwh/xsa 产物存在并记录 SHA256。资源基线及已知警告见 `docs/hw_base_summary.md`。

**限制**：ADI 期望 2025.1 而实际 2025.2；仍有 Quad SPI IOB、scoped 时钟例外、CDC 和外部 delay 提示。保留警告，后续集成和板端门禁继续验证，不能宣称全部时序或 RF 已验证。

**沉淀**：生成 wrapper 后再做端口绑定验收；构建成功同时保存资源、时序、警告、输入版本和产物哈希，避免只保留一个 bit 文件。
