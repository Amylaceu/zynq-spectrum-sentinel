## 一点五、天线接法（全程只换一次）
| 时间 | 接法 | 说明 |
|---|---|---|
| **开场（Wi-Fi 采集）** | **"W"**：2.4 GHz 胶棒拧在 **RX1A**，TX1A 空着，磁吸天线放在板旁 | 点 F14 启动后采集约 1 分钟 |
| **F14 弹出"采集完成"后，到演示结束** | **S1**：磁吸天线馈线拧在 **RX1A**，磁座离板 20–30 cm、天线竖直；胶棒拧回 **TX1A**，竖直 | 换好后在弹框点确认，接收卡片才解锁 |

- 两根都**用手拧紧**，不要用工具；拧的时候扶住 FMCOMMS3。TX2A、RX2A 一直空着。
- 磁吸天线的馈线不要和电源线、屏幕排线缠在一起；磁座最好吸在金属板上，靠窗效果更好。
- 全程不发射：TX 衰减固定 89.75 dB，TX1A 上的胶棒只是放着。
- 广播没声或很弱：先在 F8 下拉框换台；还不行就点"■ 全部停止"，把磁座挪到更靠窗或更高的位置。只挪位置，不换天线。

## 二、开场前 10 分钟准备
1. 先按 **S1** 接好天线，再接屏幕和网线，最后接 12 V 电源开机。等约 1 分钟，LCD 出现画面。
2. 笔记本打开终端，登录开发板：
   ```bash
   ssh xilinx@192.168.2.99
   ```
3. 启动演示服务（只需要这一条），然后保持这个窗口打开：
   ```bash
   sudo sh ~/start_demo.sh
   ```
4. 双击 **SentinelHost**，等顶栏显示"已连接"。
5. 笔记本接投影，把上位机窗口放到投影屏，按 **F11** 全屏。
6. 试一次广播：点 **F8 ▶ 启动**，确认喇叭出声、LCD 底栏显示频率；然后点顶栏"■ 全部停止"。
7. 打开手机 2.4 GHz 热点，放在离板约 0.5 m 处。
8. **把天线换成"W"接法**（胶棒拧到 RX1A，TX1A 空着）。准备完毕。

## 三、讲解时怎么操作
- **左栏每一行是一张功能卡片**：点 **▶** 启动，点 **■** 停止。启动一张卡会自动停掉上一张。
- 状态灯：灰 = 未运行；闪烁 = 启动中；绿 = 运行中或结果就绪；红 = 失败（再点一次 ▶ 重试）。
- **和 LCD 对照**：每张卡启动后，LCD 上都会显示卡片编号和关键数字，FPGA 卡片还会显示同一组频谱和瀑布。按 **T** 键把中间切到 LCD 数字孪生，再按 **T** 切回。
- **F14 Wi-Fi 的流程**：▶ 启动 → 弹框点"继续" → 约 1 分钟后弹出"采集完成" → 按 S1 换天线并点确认 → 其他卡片可以照常使用 → F14 灯变绿时点它看结果。
- 顶栏红色"■ 全部停止"（或 Esc）：全部停止并静音。
- 鼠标悬停在卡片的 ⓘ 上，可以看到数据口径说明，答辩追问时用。

讲解顺序（详见讲稿）：
**F14 启动 → 架构介绍 → 换天线 → F1 → F5 →（F6）→ F8 → 看 F14 结果 → F0 → F2 → F10 → F13 → 全部停止**。
F4、F7、F11、F12 留给答辩追问。

## 四、讲解结束后
1. 上位机点"■ 全部停止"。
2. 在 SSH 窗口按 `Ctrl+C`。
3. 需要断电时：
   ```bash
   sudo sync && sudo shutdown -h now
   ```
   等 10 秒以上再拔电源。**不要直接拔电源，也不要按复位键。**

## 五、常见问题
| 现象 | 处理 |
|---|---|
| 顶栏一直不显示"已连接" | 检查网线；`ping 192.168.2.99`；确认 SSH 窗口里的服务还在运行 |
| 接收卡片点不动（灰锁） | F14 之后还没确认换天线：换到 S1 后在弹框里点确认 |
| 广播没有声音 | F8 下拉框换台；检查 RX1A 是否拧紧，磁座有没有离板太近 |
| 卡片变红 | 再点一次 ▶；仍失败就跳过这一项 |
| Wi-Fi 结果迟迟没出来 | 先讲后面的卡片，F14 变绿再点；检查笔记本上 MATLAB 有没有报错 |
| LCD 不亮或板子无响应 | 按第四节关机后重启；仍不行就只用上位机讲 |
