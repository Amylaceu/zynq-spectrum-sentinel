# 三分钟现场操作脚本

本文对应100 MHz、3.84 MSPS冻结实现。先检查现场演示结果记录，再决定使用实时演示或已录制会话。所有命令以仓库根目录或板端发布目录为工作目录；开发板地址从`docs/board_info.md`读取。

## 开场准备

配置A：20–512 MHz天线接RX1A，TX1A空着，J22显示屏、2.5V跳线保持不变。板载喇叭为J36，默认音量−12 dB。电脑与开发板同网段，先验证SSH，关闭占用9000端口的旧测试。不要复位或直接断电。

板端终端进入发布目录：

```sh
cd /home/xilinx/sentinel/release/v2
sudo sh scripts/sentinel.sh verify
sudo sh scripts/sentinel.sh show A --cycles 1
```

电脑端解压完整SentinelHost目录，运行：

```powershell
.\SentinelHost.exe --connect 192.168.2.99
```

运行地址以实际开发板地址为准。按F聚焦，F11进入全屏；上位机没有发射控制。

## 0:00–1:55：A组实时展示

0:00–0:15：展示系统自检。讲解“系统检查器件、位流、温度及发射静音状态”。

0:15–1:00：展示实时频谱、瀑布、目标列表和识别点图。上位机会按演示段自动切到识别页。讲解“FPGA并行处理频谱与目标检测，处理器执行目标样本推理；类别与置信度为实验模型结果，部分调制识别仍未达到设计指标”。

1:00–1:35：板载喇叭播放已确认的95.8 MHz广播。讲解“信道选择、FM解调和音频输出已形成实际接收闭环”。如质量门控保持静音，不强行解除，转入会话回放。PC音频尚未通过长测，不演示PC监听或录音。

1:35–1:55：展示三音测试源，明确说明“这是内部已知测试源，用于功能检查”，不能称为现场收到的三路电台。内容95秒，含初始化/切换通常约110–120秒，按现场实际时长讲解，不承诺固定95秒结束。

## 1:55–2:40：交互展示

整组结束后板端主程序会退出并停止射频。需要继续交互时启动有界仅接收监测：

```sh
sudo sh scripts/sentinel.sh monitor --hostlink --seconds 120
```

在电脑点击SIG/TGT/STAT，拍摄LCD同步切页。按F展示聚焦放大。可导出当前512点IQ快照；说明这是瞬时快照，不能当作连续5秒IQ。源码版上位机新增“导出观察摘要HTML”，同时保存JSON和SHA256；旧的已打包程序若没有该按钮，使用随附的观察摘要，不声称旧版具备新功能。

尚不能展示的步骤：PC同步出声、10秒连续WAV、5秒连续IQ。相关DMA长测失败记录在`docs/g4d_progress.md`，不得用合成数据或旧录音替代实时结果。

## 2:40–3:00：异构协同与边界

展示系统资源/时序页，说明固定100 MHz、3.84 MSPS；现场演示累计混淆矩阵不等于独立正式评测。强调实时频谱、目标检出、识别显示、板载音频和远程联动的完整功能路径，同时将未达标项作为后续改进方向。

## 现场故障兜底

先正常停止板端，不复位、不拔卡：

```sh
sudo sh scripts/sentinel.sh stop
```

电脑端在解压目录回放随附真实接收会话：

```powershell
.\SentinelHost.exe --replay sessions/live_A.zsr
```

画面必须保留REPLAY标记。此路径不需要开发板，不控制LCD，也不证明当下正在接收。`show A --source replay`的板端录波驱动PL路线尚未实现，会在硬件操作前拒绝；不能把内部三音称为真实录波回放。

## B组单独录像

先停止A组并确认GPIO/SRC/audio均为0。请操作者更换为经确认的2.4 GHz天线配置B；实际直插接法需明确确认，软件发射衰减下限40 dB，RSSI高于−30 dBm立即中止。保持现场人员确认后才执行：

```sh
sudo sh scripts/sentinel.sh show B --cycles 3
```

在交互终端输入`yes`确认真实接线。发射仅在2.4 GHz ISM范围，结束恢复89.75 dB。远程非交互调用必须有明确接线确认，不能预先自动回答。B组展示“发送真值”和“模型识别”差异，不隐藏误分类。

全部测试结束后，由操作者恢复配置A。关机前执行：

```sh
sudo sync && sudo shutdown -h now
```

确认串口显示系统已停止后才断电、取SD卡。整卡备份与工程ZIP分别保存，不能把工程ZIP当作SD镜像。
