# 三机位录像清单

以真实运行画面为准，不拼接成未实际验证过的同步功能。保持每段原始视频，记录主机UTC时间和对应测量目录。开发板时钟尚不准确，不能只凭屏幕系统时间对齐。

| 镜头 | 机位与内容 | 建议时长 | 真实性标注 |
|---|---|---:|---|
| 全景 | 手机固定拍开发板、RX1A天线和J22屏，配置A | 10秒 | 100 MHz、3.84 MSPS；TX关闭 |
| 实时监测 | 手机拍LCD；电脑同时录上位机全屏 | 20秒 | PS界面使用板端原始帧，PL为抽样重建 |
| 联动点击 | 手机拍LCD，电脑录点击SIG/TGT/STAT，后期左右分屏 | 15秒 | 真实点击到LCD变化；不加速掩盖延迟 |
| 识别 | 上位机识别页、Top-5、星座点图 | 15秒 | 八大类未校准分数，误识别如实展示 |
| 广播声音 | 手机录板载喇叭与LCD；环境安静，音量−12 dB | 20秒 | 实际板载FM，不标为PC监听或WAV录音 |
| 内部测试 | LCD与上位机三音段 | 10秒 | 内部已知测试源，非三路外部信号 |
| 手机监看 | 第三机位拍另一手机浏览器访问开发板8080端口 | 5–10秒 | 仅接收监看，无发射控制 |
| 数据留存 | 电脑录保存会话、512点快照和观察摘要 | 15秒 | 快照非连续IQ；摘要非正式评测报告 |
| PC回放 | 断开实时连接，用真实.zsr会话回放 | 10秒 | 明确REPLAY，不能剪掉模式标签 |
| B组 | 停止射频、确认换线后，另录2.4 GHz闭环 | 20秒 | 发射类别和识别类别同时显示；演示累计非正式评测 |
| 收尾 | TX恢复89.75 dB，停止GPIO/SRC/audio归零 | 5秒 | 保留原始JSON与SHA256 |

OBS仅用于桌面录屏，本仓库不自动安装或操作OBS。录制前清理通知和含个人信息的窗口。录像合成时以手机录到的板载喇叭声音为本阶段音频来源；PC连续音频和WAV没有通过验收，不能声称来自上位机录音。未来通过验收后才补录“PC监听→录音→试听”的20秒镜头。

配置A与B分开录制。更换天线前停止射频，保持板卡供电与SD卡不动；需要关机时先sync和shutdown，确认停止后再断电。
